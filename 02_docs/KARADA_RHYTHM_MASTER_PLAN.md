## 1. 企画概要・コンセプト

### 1.1 背景と課題意識
- 世の中に溢れる「生活の裏ワザ・ライフハック」の多くは、誰でも知っている陳腐な豆知識（Tier C）か、情報商材的な過剰な煽り（「人生激変」「〜法」など）に二極化している。
- 一方で、「運動」「睡眠」「疲労回復」「姿勢」「食事」といった**人間の身体活動に根差した知恵**は、老若男女問わず365日一生モノの需要がある（エバーグリーン領域）。
- 本企画は、**「その道のプロ（理学療法士、睡眠専門医、医師、アスリートトレーナー等）」が発信する現場知・解剖学的知見**をYouTubeから継続的に収集・構造化し、note読者に「文字だけで即試せて納得できる心地よい波」を提供する。

### 1.2 連載名と佇まい
- **連載名**: **『からだリズム』**
- **サブコピー**: *専門家と現場の知恵で、心地よい波をととのえる*
- **トーン＆マナー**:
  - 軽薄な「ライフハック」や硬い漢語を排し、ひらがな3音＋カタカナ3音の心地よいリズム（からだリズム）を軸とする。
  - 煽らない・断定しない。解剖学や生体メカニズムに基づく「1行の納得感」を添える。
  - 世間の当たり前（Tier C）を否定せず、対比用の文脈として活かしながらプロの結論（Tier A）を提示する。
- **将来展望（こころリズムとの連携）**:
  - 本シリーズ『からだリズム』（身体・睡眠・運動編）の基盤が確立した段階で、メンタル・自律神経・感情の波を整える姉妹シリーズ**『こころリズム』**を展開し、全体として『からだとこころのリズム』ブランドへ発展させる。

## 3. システムアーキテクチャ・パイプライン

### 3.1 ディレクトリ構成
```

├── 01_channels/

├── 02_docs/

│   ├── raw_transcripts/          # 字幕生データ（JSON）
```

### 3.2 収集フロー（GitHub Actions / クラウド半自動）
1. **RSS差分検知**: YouTube公式Atomフィードを叩き、未処理の動画を特定（APIキー不要・レート制限なし）。
2. **安全インターバル取得**: 1回の実行あたり最大2〜3本に限定し、動画間に15〜30秒の待機を挿入してIPブロックを完全回避。
3. **字幕（文字起こし）取得**: `youtube-transcript-api` により日本語テキストを高速抽出。
4. **LLM構造化**: Gemini API を用い、プロンプトに従って「悩み」「旧常識（Tier C）」「プロの解決策（Tier A）」「メカニズム」「アクション」をJSON抽出。
5. **DB蓄積**: `wisdom_db.jsonl` に追記コミット。

### 3.3 トピック・クラスタリングと裏付け品質ゲート（5〜10ソース原則）

単一の専門家や1〜2本の動画情報だけで拙速に記事化することを永久に禁止し、以下の**厳格な母集団・品質ゲート**を設ける。

1. **【5〜10ソース原則（Cross-Source Evidence Gate）】**:
   - 1つのトピック（例：「睡眠時間の確保と中途覚醒」「首こりと広頚筋」「朝散歩と体内時計」など）につき、**最低でも5件、理想としては10件の関連ソース**がデータベース上に蓄積・クラスタリングされるまで、記事化プロセス（執筆・ドラフト生成）へ移行してはならない。
   - 蓄積数が5件未満のトピックは「検証中（Collecting）」としてストックを継続する。

2. **【多角的分析の3大照合軸（慎重な分析基準）】**:
   - **① 発信者属性の立体性（Authority Mix）**:
     - 「基礎研究（大学教授・研究機構）」の理論的発見
     - 「臨床現場（専門外来・医師）」の患者実態と診断知見
     - 「身体操作（理学療法士・トレーナー）」の具体的な身体の動かし方・再現手順
     - ※これら異なる立場の専門知が突き合わされているかを検証する。
   - **② 情報の鮮度（Timeline Freshness）**:
     - 発信日時（いつ）を厳格に照合し、過去の古い俗説（〜2020年頃の常識）と最新エビデンス（2024〜2026年）の時間的変遷を整理する。古い情報で新しい知見を上書きしない。
   - **③ 3層検証構造（主張・裏付け・反証）**:
     - **主主張（Core Insight）**: トピックの核となるプロの指摘。
     - **裏付け（Supporting Evidence）**: 別機関・他分野の専門家による科学的・客観的合致。
     - **反証・例外条件（Counter & Caveats）**: 「ただし、〇〇な人・高齢者・特定の持病がある人には逆効果」といった臨床現場のリアルな例外・注意点の明記。

## 4. note記事フォーマット設計

1記事あたり **7〜10個の知恵** を収録。

### 各項目の基本構造
> ### 01. 【悩み】デスクワークで首がガチガチ・首の後ろを揉んでも治らないとき
> - **世間の思い込み（Tier C）**: 首がこったら首の後ろを揉むか、首をぐるぐる回せばいい
> - **専門家の調律アプローチ（Tier A）**: 両手で鎖骨を押さえて斜め上を見上げ、一度口を開けて顎を突き出してから口を閉じる（広頚筋ストレッチ）
> - **なぜ効くのか（メカニズム）**: 下を向く姿勢で首の前側の薄い筋肉（広頚筋）が縮むと、後ろの僧帽筋が常に引っ張られて凝り固まります。鎖骨を固定して前側を物理的に最大伸張することで、引っ張りが根本から解除されます。
> - **今すぐできる30秒アクション**: 左右各30秒、痛気持ちいい範囲で伸ばす。
