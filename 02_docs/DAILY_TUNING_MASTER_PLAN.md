## 1. 企画概要・コンセプト

### 1.1 背景と課題意識
- 世の中に溢れる「生活の裏ワザ・ライフハック」の多くは、誰でも知っている陳腐な豆知識（Tier C）か、情報商材的な過剰な煽り（「人生激変」「〜法」など）に二極化している。
- 一方で、「運動」「睡眠」「疲労回復」「姿勢」「食事」といった**人間の身体活動に根差した知恵**は、老若男女問わず365日一生モノの需要がある（エバーグリーン領域）。
- 本企画は、**「その道のプロ（理学療法士、睡眠専門医、医師、アスリートトレーナー等）」が発信する現場知・解剖学的知見**をYouTubeから継続的に収集・構造化し、note読者に「文字だけで即試せて納得できる調律の引き出し」を提供する。

### 1.2 連載名と佇まい
- **連載名**: 『日常調律手帖』
- **サブコピー**: *専門家と現場の知恵で、身体と暮らしを整える*
- **トーン＆マナー**:
  - 軽薄な「ライフハック」という言葉を排し、誠実で知的な「身体の調律（チューニング）」を軸とする。
  - 煽らない・断定しない。解剖学や生体メカニズムに基づく「1行の納得感」を添える。
  - 世間の当たり前（Tier C）を否定せず、対比用の文脈として活かしながらプロの結論（Tier A）を提示する。

## 2. 情報価値のランク定義（Tier基準）

| ランク | 定義 | 具体例 | 企画内での役割 |
| :---: | :--- | :--- | :--- |
| **Tier A** | **専門家・プロの現場知**<br>（解剖学・生体リズムに基づく具体的アプローチ） | ・首こりの真因となる「広頚筋」の伸長手順<br>・大胸筋下部を狙うデスク活用回旋ストレッチ<br>・メラトニン分泌逆算による日光浴タイミング | **記事の主役（コアバリュー）** |
| **Tier B** | **実践・検証済みのTips**<br>（現場での工夫・道具の使い分け） | ・PCマウス特有の前腕伸筋群ケア<br>・就寝前スマホのグレイスケール（白黒）化 | **実用性を高める補強ネタ** |
| **Tier C** | **一般常識・AI即答レベル**<br>（ネットで周知の当たり前） | ・首をぐるぐる回す<br>・寝る前スマホを見ない<br>・深呼吸をする | **対比用の踏み台（前振り）** |

## 3. システムアーキテクチャ・パイプライン

### 3.1 ディレクトリ構成
```
daily_tuning/
├── 01_channels/
│   └── channels.json             # 厳選した専門家YouTubeチャンネル一覧
├── 02_docs/
│   └── DAILY_TUNING_MASTER_PLAN.md # 本仕様書（正本）
├── 03_data/
│   ├── processed_videos.json     # 収集済み動画ID管理（重複防止）
│   ├── raw_transcripts/          # 字幕生データ（JSON）
│   └── wisdom_db.jsonl           # 構造化された知恵マスターデータベース
└── 04_scripts/
    ├── collect_transcripts.py    # RSS差分検知＆字幕安全収集スクリプト
    ├── extract_wisdom.py         # LLM構造化＆Tier判定スクリプト
    └── generate_article_draft.py # note記事ドラフト自動生成スクリプト
```

### 3.2 収集フロー（GitHub Actions / クラウド半自動）
1. **RSS差分検知**: YouTube公式Atomフィードを叩き、未処理の動画を特定（APIキー不要・レート制限なし）。
2. **安全インターバル取得**: 1回の実行あたり最大2〜3本に限定し、動画間に15〜30秒の待機を挿入してIPブロックを完全回避。
3. **字幕（文字起こし）取得**: `youtube-transcript-api` により日本語テキストを高速抽出。
4. **LLM構造化**: Gemini API を用い、プロンプトに従って「悩み」「旧常識（Tier C）」「プロの解決策（Tier A）」「メカニズム」「アクション」をJSON抽出。
5. **DB蓄積**: `wisdom_db.jsonl` に追記コミット。

## 4. note記事フォーマット設計

1記事あたり **7〜10個の知恵** を収録。

### 各項目の基本構造
> ### 01. 【悩み】デスクワークで首がガチガチ・首の後ろを揉んでも治らないとき
> - **世間の思い込み（Tier C）**: 首がこったら首の後ろを揉むか、首をぐるぐる回せばいい
> - **専門家の調律知恵（Tier A）**: 両手で鎖骨を押さえて斜め上を見上げ、一度口を開けて顎を突き出してから口を閉じる（広頚筋ストレッチ）
> - **なぜ効くのか（メカニズム）**: 下を向く姿勢で首の前側の薄い筋肉（広頚筋）が縮むと、後ろの僧帽筋が常に引っ張られて凝り固まります。鎖骨を固定して前側を物理的に最大伸張することで、引っ張りが根本から解除されます。
> - **今すぐできる30秒アクション**: 左右各30秒、痛気持ちいい範囲で伸ばす。

## 5. ロードマップ

- **フェーズ1（基盤構築・検証）**: スクリプトの試作、厳選チャンネル（10件）の登録、1〜5件の抽出テスト【完了】
- **フェーズ2（定期自動化）**: GitHub Actionsによる定期実行パイプラインのデプロイ、数十件の知恵蓄積
- **フェーズ3（第1話執筆・公開）**: 「デスクワーク・姿勢・首肩の調律」をテーマにした初記事のプロット作成・校正・note公開
- **フェーズ4（1000件スケール）**: チャンネル拡充（睡眠、消化器、歩行、自律神経）、1000件の調律データベース完成
